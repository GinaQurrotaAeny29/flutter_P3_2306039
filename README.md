## Deskripsi Proyek

Proyek ini merupakan aplikasi mobile sederhana yang dibuat menggunakan framework Flutter dan bahasa pemrograman Dart. Aplikasi ini dibuat sebagai bagian dari tugas praktikum pemrograman mobile.

Pada proyek ini, aplikasi menampilkan antarmuka pengguna dengan beberapa komponen widget Flutter seperti AppBar, teks, ikon, dan elemen layout lainnya. Flutter menggunakan konsep widget untuk membangun tampilan aplikasi sehingga pengembangan UI menjadi lebih terstruktur dan mudah dipahami.

Proyek ini bertujuan untuk memperdalam pemahaman mengenai pembuatan aplikasi mobile menggunakan Flutter serta mempraktikkan penggunaan berbagai widget dasar dalam membangun tampilan aplikasi.

## Teknologi yang Digunakan

* Flutter
* Dart
* Visual Studio Code
* Android Emulator atau perangkat Android

Flutter merupakan framework open-source yang digunakan untuk mengembangkan aplikasi mobile dengan satu basis kode untuk berbagai platform seperti Android dan iOS. ([Flutter Book][1])

## Struktur Proyek

Struktur dasar proyek Flutter umumnya terdiri dari beberapa folder utama seperti berikut:

```
flutter_P3_2306039
│
├── lib/
│   └── main.dart
│
├── android/
├── ios/
├── pubspec.yaml
└── README.md
```

Folder **lib** berisi seluruh kode Dart untuk aplikasi, sedangkan file **main.dart** merupakan titik awal (entry point) ketika aplikasi dijalankan. ([Flutter Book][1])

## Cara Menjalankan Aplikasi

1. Clone repository

```
git clone https://github.com/GinaQurrotaAeny29/flutter_P3_2306039.git
```

2. Masuk ke folder project

```
cd flutter_P3_2306039
```

3. Install dependency

```
flutter pub get
```

4. Jalankan aplikasi

```
flutter run
```
